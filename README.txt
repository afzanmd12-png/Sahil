ALINA'S BIRTHDAY SURPRISE WEBSITE
================================

Files:
- index.html: the website
- assets/floral-heart.jpg: crop of the calendar reference artwork
- assets/background-music.mp3: the audio file supplied in the chat

Preview:
Open index.html in Chrome. Keep the assets folder beside it.

Publishing:
Upload the entire folder (not just index.html) to a static website host to get a shareable URL.
The music file is included as supplied. Before making the site public, make sure you have permission to publicly use that recording. If not, replace assets/background-music.mp3 with a track you are licensed to use.

Notes:
- Music starts after the welcome button is tapped, and can be toggled with the Music button.
- The site is mobile-first and responsive.
- The calendar uses the floral-heart artwork from the provided reference screenshot, with November 2026 dates and November 10 highlighted.
